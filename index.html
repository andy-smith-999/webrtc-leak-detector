WebRTC Leak Detector

Browser-side tool that gathers ICE candidates via RTCPeerConnection, classifies host / srflx / relay / mDNS addresses, and compares public candidates against an optional HTTP egress IP. Local and mDNS addresses are not treated as public leaks.

This page is not fully offline. ICE gathering contacts a STUN server (default: Google public STUN). The optional IP lookup sends a request to a third-party HTTP API. See privacy.md.
